
# 🤖 مستشار | هوش مصنوعی شخصی

**مستشار** یک دستیار هوش مصنوعی شخصی است که با هدف کمک به کاربر در تصمیم‌گیری، مشاوره، برنامه‌ریزی و انجام کارهای روزمره طراحی شده است.

هدف پروژه این است که کاربر بتواند به‌جای استفاده از یک چت‌بات عمومی، دستیار هوشمند خودش را با نام، شخصیت، توضیحات و پروفایل اختصاصی تنظیم کند.

## ساختار و عملکرد پروژه

پروژه امکان استفاده از چند مدل هوش مصنوعی را فراهم می‌کند:

- **Proposers:** مدل‌هایی که پاسخ‌ها و پیشنهادهای اولیه را تولید می‌کنند.
- **Judge:** مدل داوری که خروجی مدل‌های دیگر را بررسی و ارزیابی می‌کند و پاسخ نهایی را شکل می‌دهد.
- **Personal Profile:** اطلاعات و ترجیحات کاربر برای شخصی‌سازی پاسخ‌ها.
- **Bot Personality:** تعیین نام، شخصیت و نحوه رفتار دستیار.

# ⚙️ راه‌اندازی و تنظیمات

برای اجرای پروژه ابتدا باید فایل `.env` را در مسیر اصلی بک‌اند ایجاد و تنظیم کنید.

## نمونه فایل ENV

```env
# ================== BeatAPI (یک آدرس، یک کلید برای همه‌ی مدل‌ها) ==================
BEATAPI_BASE_URL=
# کلید را فقط همین‌جا بگذار؛ در چت یا Angular نگذار
BEATAPI_API_KEY=

# ================== عمومی ==================
APP_TOKEN=
CORS_ORIGINS=http://localhost:4200
REQUEST_TIMEOUT=90

# ================== مدل‌ها (ID دقیق طبق مستندات BeatAPI) ==================
PROPOSERS=

PROPOSER_MAX_TOKENS=8000
JUDGE_MAX_TOKENS=8000

# ================== مستشار ==================
BOT_NAME=مستشار
# true = مشخصات تو برای همه‌ی مدل‌ها فرستاده می‌شود | false = فقط برای داور
SHARE_PROFILE_WITH_PROPOSERS=true

BOT_DESCRIPTION=""
USER_PROFILE=""
```

---

## 1. تنظیمات اتصال به BeatAPI

### BEATAPI_BASE_URL
آدرس پایه API سرویس BeatAPI است که درخواست‌های هوش مصنوعی به آن ارسال می‌شوند.

آدرس دقیق را از مستندات BeatAPI دریافت کنید.

### BEATAPI_API_KEY
کلید اختصاصی API برای احراز هویت و استفاده از مدل‌های هوش مصنوعی است.

**نکته امنیتی:** این کلید را فقط در بک‌اند و فایل `.env` قرار دهید. هرگز آن را در Angular، GitHub یا کدهای سمت کاربر قرار ندهید.

---

## 2. تنظیمات عمومی

### APP_TOKEN
توکن داخلی برنامه برای اعتبارسنجی درخواست‌ها، در صورتی که در بک‌اند پیاده‌سازی شده باشد.

یک مقدار تصادفی، طولانی و غیرقابل حدس برای آن انتخاب کنید.

### CORS_ORIGINS
آدرس‌هایی که اجازه ارسال درخواست به بک‌اند را دارند.

برای اجرای محلی Angular:

```env
CORS_ORIGINS=http://localhost:4200
```

در زمان انتشار پروژه باید آدرس دامنه واقعی فرانت‌اند نیز مطابق قالب پشتیبانی‌شده توسط بک‌اند تنظیم شود.

### REQUEST_TIMEOUT
حداکثر مدت زمان انتظار برای دریافت پاسخ از API بر حسب ثانیه.

مقدار پیش‌فرض:

```env
REQUEST_TIMEOUT=90
```

یعنی برنامه حداکثر ۹۰ ثانیه برای پاسخ منتظر می‌ماند.

---

## 3. تنظیم مدل‌های هوش مصنوعی

### PROPOSERS

در این قسمت شناسه مدل‌هایی را وارد کنید که قرار است پاسخ‌های اولیه را تولید کنند.

برای مثال:

```env
PROPOSERS=model-id-1,model-id-2,model-id-3
```

شناسه‌ها باید دقیقاً مطابق مستندات BeatAPI باشند.

**توجه:** نام نمایشی مدل لزوماً با شناسه API آن یکسان نیست.

### PROPOSER_MAX_TOKENS

حداکثر تعداد توکن خروجی برای هر یک از مدل‌های پیشنهاددهنده.

مقدار پیش‌فرض:

```env
PROPOSER_MAX_TOKENS=8000
```

### JUDGE_MAX_TOKENS

حداکثر تعداد توکن خروجی مدل داور.

مقدار پیش‌فرض:

```env
JUDGE_MAX_TOKENS=8000
```

افزایش این مقادیر می‌تواند امکان تولید پاسخ‌های طولانی‌تر را فراهم کند، اما ممکن است مصرف اعتبار و زمان پاسخ‌گویی را افزایش دهد.

## 4. شخصی‌سازی مستشار

### BOT_NAME

نام دستیار هوش مصنوعی.

```env
BOT_NAME=مستشار
```

می‌توانید نام دلخواه خودتان را جایگزین کنید.

### SHARE_PROFILE_WITH_PROPOSERS

مشخص می‌کند اطلاعات پروفایل کاربر برای کدام مدل‌ها ارسال شود.

```env
SHARE_PROFILE_WITH_PROPOSERS=true
```

- `true`: مشخصات کاربر برای مدل‌های پیشنهاددهنده و داور ارسال می‌شود.
- `false`: مشخصات کاربر فقط برای مدل داور ارسال می‌شود.

### BOT_DESCRIPTION

مهم‌ترین بخش برای تعیین شخصیت و رفتار مستشار است.

در این قسمت باید توضیح دهید که مستشار چه شخصیتی دارد، چگونه صحبت می‌کند و چه وظایفی بر عهده دارد.

نمونه:

```env
BOT_DESCRIPTION="تو مستشار، یک دستیار هوش مصنوعی شخصی هستی. وظیفه تو کمک به کاربر در تصمیم‌گیری، مشاوره، برنامه‌ریزی و انجام کارهای روزمره است. با لحنی دوستانه، صمیمی و مشاورگونه صحبت کن. شوخ‌طبع باش، اما در موضوعات جدی دقت و مسئولیت‌پذیری را حفظ کن. روحیه‌بخش باش، اما واقعیت را پنهان نکن. پاسخ‌هایت دقیق، کاربردی و متناسب با شرایط کاربر باشند. پیش از پاسخ دادن، تمام جوانب موضوع را بررسی کن و از ارائه اطلاعات نادرست خودداری کن."
```

این متن صرفاً نمونه است و می‌توانید آن را مطابق سلیقه خود تغییر دهید.

### USER_PROFILE

این قسمت برای معرفی کاربر به هوش مصنوعی است.

هر اطلاعاتی که برای شخصی‌سازی پاسخ‌ها مفید باشد می‌تواند در این قسمت قرار بگیرد؛ مانند:

- رشته تحصیلی و زمینه کاری
- مهارت‌ها و تخصص‌ها
- علایق و اهداف شخصی
- نحوه یادگیری و مطالعه
- ترجیحات در نحوه پاسخ‌گویی
- پروژه‌ها و فعالیت‌های جاری

نمونه:

```env
USER_PROFILE="کاربر دانشجوی مهندسی کامپیوتر است و در حوزه برنامه‌نویسی فعالیت می‌کند. به توسعه نرم‌افزار و هوش مصنوعی علاقه دارد. ترجیح می‌دهد پاسخ‌ها ساده، مختصر، جامع و کاربردی باشند. در موضوعات آموزشی توضیحات مرحله‌به‌مرحله همراه با مثال ارائه شود."
```

**نکته:** از قرار دادن رمز عبور، کلیدهای API، اطلاعات بانکی و سایر اطلاعات حساس در پروفایل خودداری کنید.

# 🔐 نکات امنیتی

1. فایل `.env` نباید در GitHub منتشر شود.
2. فایل `.env` را به `.gitignore` اضافه کنید.
3. کلید BeatAPI را فقط در بک‌اند نگهداری کنید.
4. توکن APP_TOKEN را در اختیار افراد غیرمجاز قرار ندهید.
5. برای انتشار پروژه، مقادیر توسعه محلی مانند CORS را به آدرس‌های واقعی تغییر دهید.
6. در صورت انتشار تصادفی کلید API، آن را باطل کرده و کلید جدید ایجاد کنید.

برای نمونه فایل `.gitignore`:

```gitignore
.env
.env.*
!.env.example
```
